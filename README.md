# RTT vs File Download Time — Network Performance Experiment

Empirical study measuring the relationship between **Round-Trip Time (RTT)** and **HTTPS file download time** across three geographically distributed OVH proof servers (France, Canada, Singapore). Designed for reproducible data collection and publication-ready analysis figures.

## Overview

| Item | Detail |
|------|--------|
| **Client** | Single machine (Windows + `curl.exe`) |
| **File** | `10Mb.dat` (10 MB) per server |
| **Regions** | France (Europe), Canada (North America), Singapore (Asia) |
| **Samples** | 30 per region (+ 2 warm-up runs), 90 total raw measurements |
| **Metrics** | RTT (TCP connect time), download duration, throughput (Mbps) |

- Network access to OVH proof servers

### Analysis (`analyze.py`)

- Python 3.8+
- Dependencies in `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Usage

### 1. Run the experiment

From the project directory:

```bash
python experiment.py
```

This will:

1. Verify each server's file size via HTTP `Content-Length`
2. Run 2 warm-up downloads per region
3. Collect 30 samples per region (RTT → full download)
4. Write results to `experiment_results.csv`

**Console output** includes per-sample RTT, download time, throughput, and regional averages.

### 2. Analyze results and generate figures

```bash
python analyze.py
```

Optional arguments:

```bash
python analyze.py --csv experiment_results.csv --outdir .
python analyze.py --no-outlier-filter   # skip IQR outlier removal
```

**Outputs** (PNG @ 300 dpi + PDF for LaTeX):

| File | Description |
|------|-------------|
| `fig1_workflow.pdf` | Experimental procedure diagram |
| `fig2_regression.pdf` | RTT vs download time scatter + overall regression |
| `fig3_violin.pdf` | Download time distribution by region (violin + jitter) |
| `fig4_cdf.pdf` | Cumulative distribution of download times (log x-axis) |
| `summary_table.csv` | Per-region summary statistics for paper tables |

## Data Format

`experiment_results.csv` columns:

| Column | Description |
|--------|-------------|
| `Timestamp` | ISO 8601 sample time |
| `Region` | France, Canada, or Singapore |
| `Sample` | Sample index (1–30) |
| `RTT_ms` | TCP connect time in milliseconds |
| `Download_s` | Full file download time in seconds |
| `Throughput_Mbps` | `(file_size_MB × 8) / Download_s` |

## Analysis Notes

- **Outlier removal:** By default, `analyze.py` applies per-region IQR filtering (1.5×) on both RTT and download time. From 90 raw samples, 8 outliers are typically removed, yielding **N = 82** clean samples.
- **Overall Pearson correlation** (RTT vs download time, all regions): **r ≈ 0.75**
- **Within-region correlations** are weak (France ≈ −0.26, Canada ≈ +0.04, Singapore ≈ +0.11), indicating that geographic path dominates over local RTT noise.
- **One-way ANOVA** on download times: **F(2, 79) ≈ 118**, **p < 0.001**
